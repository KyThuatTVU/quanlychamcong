Cấu Hình Đăng Nhập Google (Google OAuth 2.0)
Đang kiểm tra...

Hệ thống sử dụng thư viện chính thức Google Identity Services để xác thực nhanh và bảo mật không cần mật khẩu.

Hướng dẫn tạo Google Client ID (Chỉ làm 1 lần):
  1. Truy cập Google Cloud Console → Credentials
  2. Nhấn Create Credentials → OAuth client ID, chọn loại Web application.
  3. Tại mục Authorized JavaScript origins, thêm địa chỉ: http://localhost
  4. Sao chép chuỗi Client ID dán vào ô bên trên rồi nhấn nút Lưu Client ID.
